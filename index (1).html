🛡️ Sobre SECURITY JADC

SECURITY JADC es una aplicación para Android diseñada para ayudar a proteger y organizar fotografías, videos y otros archivos mediante PIN, autenticación biométrica, exploración de archivos y navegación web integrada.

02Datos y permisos utilizados

La aplicación puede solicitar acceso a fotografías, videos y archivos seleccionados por el usuario para permitir su visualización, organización e incorporación a la bóveda. Solicita acceso biométrico cuando el usuario elige utilizar la huella digital. También utiliza acceso a Internet y al estado de la red para el navegador integrado y otras funciones que lo requieran.

La autenticación biométrica se realiza mediante los mecanismos de Android; la aplicación no necesita recibir ni almacenar imágenes de las huellas digitales.

03Archivos privados y credenciales

Las fotografías, videos y archivos incorporados a la bóveda se gestionan en el dispositivo conforme a las funciones disponibles en la aplicación. El PIN y la información necesaria para controlar el acceso se utilizan para autenticar al usuario. La protección concreta, el cifrado y la eliminación de los archivos dependen de la implementación de la versión instalada.

El usuario debe conservar respaldos independientes de archivos importantes. La desinstalación, el borrado de datos o la pérdida de credenciales pueden impedir el acceso a contenido almacenado localmente.

04Navegador privado

El navegador integrado requiere conexión a Internet. Los sitios web visitados pueden procesar datos como dirección IP, cookies, identificadores y datos introducidos por el usuario, conforme a sus propias políticas. El modo privado de SECURITY JADC no garantiza anonimato frente a sitios web, proveedores de Internet u otros servicios externos.

La aplicación puede ofrecer funciones para limpiar datos de navegación, pero el comportamiento exacto de cookies, caché y almacenamiento web depende también de Android WebView y del sistema operativo.

05Publicidad y compras dentro de la aplicación

En la versión inicial prevista para pruebas, los anuncios y las opciones de compra están desactivados. La aplicación puede conservar componentes técnicos de Google AdMob y Google Play Billing para versiones futuras. Si se habilitan anuncios o compras en una actualización, esta política y las declaraciones correspondientes de Google Play se revisarán para reflejar los tratamientos de datos aplicables.

06Compartición con terceros

Al abrir páginas externas en el navegador, los sitios visitados pueden recibir datos técnicos necesarios para establecer la conexión. Los servicios del sistema Android y Google Play pueden procesar información conforme a sus propias políticas cuando sus funciones se utilizan. Esta política no debe interpretarse como una afirmación de que ningún dato sale del dispositivo en todas las circunstancias.

07Conservación y eliminación

Los archivos y preferencias almacenados localmente permanecen en el dispositivo hasta que el usuario los elimina mediante las funciones disponibles o se borran los datos de la aplicación, sujeto al comportamiento del sistema operativo. La eliminación de datos de sitios externos debe gestionarse también ante dichos sitios cuando corresponda.

08Seguridad

SECURITY JADC incorpora controles de acceso mediante PIN y, cuando el dispositivo lo permite, autenticación biométrica. Ninguna medida de seguridad ofrece protección absoluta. Se recomienda mantener Android actualizado, proteger el dispositivo y evitar compartir el PIN.

09Menores de edad

SECURITY JADC no se presenta como un servicio dirigido específicamente a niños. El uso de la aplicación debe ajustarse a la edad y a la clasificación de contenido declaradas en Google Play.

10Cambios en esta política

Podemos actualizar esta política cuando cambien las funciones, los proveedores o los requisitos legales. La versión vigente se publicará en esta misma dirección, con su fecha de actualización.

11Consultas y derechos

Para consultas sobre privacidad o tratamiento de datos, escribe a justicialiga777@gmail.com. Cuando los datos estén almacenados únicamente en el dispositivo, el usuario podrá gestionarlos mediante las funciones disponibles de la aplicación y Android.
